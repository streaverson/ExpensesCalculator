## 📝 Description
This project is a functional **Expenses Calculator** built from scratch using **Vanilla JavaScript**, **HTML5**, and **CSS3**. 

The main goal of this project is to demonstrate how to handle real-world data logic without relying on heavy frameworks like React. It is designed as a step-by-step tutorial to help beginners master DOM manipulation, event handling, and array methods.

## 🚀 Key Learning Objectives
By following this project, you will learn:
- **DOM Manipulation:** How to dynamically add, remove, and update elements.
- **State Management:** Handling an array of expense objects in pure JavaScript.
- **Mathematical Logic:** Calculating total balances, income, and expenditures.
- **Event Listeners:** Managing user inputs and form submissions efficiently.
- **Data Persistence:** (Optional: if you used LocalStorage, mention it here!)

## 🛠️ Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Modern styling (Flexbox/Grid).
- **JavaScript (ES6+)**: Core logic and interactivity.
